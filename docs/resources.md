# Resources

A small, curated collection of Go resources — not an exhaustive list, just things worth pointing a developer to depending on where they are in their journey.

## Official

- [go.dev](https://go.dev) — the language's official home: docs, spec, releases
- [Effective Go](https://go.dev/doc/effective_go) — still one of the best "how to write idiomatic Go" guides
- [A Tour of Go](https://go.dev/tour/) — interactive intro for absolute beginners

## Going deeper

- [Go by Example](https://gobyexample.com/) — short, annotated code snippets for common patterns
- [Go Concurrency Patterns (talks)](https://go.dev/talks/2012/concurrency.slide) — Rob Pike's classic on goroutines and channels
- [The Go Blog](https://go.dev/blog/) — official team writing on language changes and internals

## Community

- Our own [blog](/blog) — production notes, build logs, and backend engineering write-ups from GolangForAll contributors
- [r/golang](https://www.reddit.com/r/golang/) — active discussion, though signal-to-noise varies

This list will grow as the community contributes more. If there's something you found genuinely useful and think belongs here, mention it in the WhatsApp group.
